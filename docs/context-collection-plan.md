# Context Collection Plan

User context should be collected in layers.

## Static Profile

- Preferred language.
- Screen reader.
- Verbosity level.
- Form assistance preference.
- Image description preference.
- Navigation preference.

## Session Context

- Current URL/domain.
- Current page type.
- Active element.
- Recent focus path.
- Current task hint.
- Form interaction state.

## Behavior Context

- Repeated focus patterns.
- Frequently skipped sections.
- Frequently used shortcuts.
- Repeated form errors.
- Feature usage preferences.

This addresses the proposal feedback: user context collection should be more structured and adaptive.
